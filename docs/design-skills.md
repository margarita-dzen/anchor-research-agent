# Дизайн скилове: кога кой (22.10.2026)

**Правило: клон = без редизайн; адаптация към бранда = дизайн скилове; проверка = audit скилове; оферта = CRO.**

| Ситуация | Скилове | Защо |
|---|---|---|
| Абсолютен клон, режим **keep** (външна медия / лична история, `clone_mode.py`) | **никакви дизайн скилове** | Задачата е формата 1:1. Дизайн скил „подобрява“ и отдалечава клонинга от примера (грешката с Karbonoir v1). |
| Абсолютен клон, режим **brand** (основният домейн на клиента) | `client-lp-context` (зарежда DESIGN.md) → `impeccable` / `design-taste-frontend` | Структурата е 1:1, а цветовете, шрифтовете, бутоните и разстоянията идват от бранда. Скиловете правят адаптацията да изглежда като сайта на клиента, не като шаблон. |
| Проверка след **всеки** клон | `web-design-guidelines`, `impeccable` (audit) | Четимост на 390, контраст, размер на бутоните (≥ 44 px), без хоризонтален скрол. Само поправки на проблеми, не редизайн. |
| Офертният блок и CTA-тата | `cro`, `landing-page-review` | Те не са клонирани 1:1, а са наши (PDP пакетът). Само там се оптимизира. |
| Шаблоните за преглед (Shelly стил) | `ui-ux-pro-max` | Чист и бърз интерфейс за одобрение. |
| Нова страница без пример | `client-lp-context` → `impeccable` / `design-taste-frontend` / `frontend-design` + `seo-optimization` | Тук свобода на дизайна. |

Забележка: `seo-optimization` е задължителен за всяка нова страница (feedback_seo_skill_every_page), но при скрити адвърториали (seo.hidden=1) се прилага само за заглавие, мета и alt текстове.
